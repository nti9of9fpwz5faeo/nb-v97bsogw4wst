# v67 花の採取・試作

ダイヤハンターの通常出現と調整UIを休止し、通常プレイに花を1個追加する。以前のダイヤ・ランク・ミッション・ハンター設定の保存データは保持する。

- 最初のコースの14マス目に白金の花。チュートリアルには出現しない。
- 花の上でブレイク長押し。200ms後から加算し、累計2500msで花を1個獲得。
- 長押しを離しても蓄積を保持。離脱時は途中経過をリセット。ワープで花は再出現しない。
- 通常ノーツは押し直してブレイク。自動ブレイクはしない。紫は進むで処理するが前進・後続ノーツの押し返しは行わない。
- 花の上では必殺技を禁止。採取完了後も同じ長押しから必殺技へ移行しない。新しい長押しで通常機能へ戻る。
- 被弾の既存ルールは維持。ポーズ・終了中は採取しない。必殺技で通過するだけでは獲得しない。
- 花は獲得時に専用localStorageへ保存。ホームとリザルトに花の所持数・獲得数を表示。ダイヤ換算なし。
- Canvas描画で花・足元ゲージ・短い獲得演出を追加。

検証: tests/flower-browser.test.cjs（入力、紫、長押し、ゲージ保持/離脱、必殺技、ポーズ/終了/ワープ、保存、狭い画面）、既存engine/playtest/chase-coursesテスト。旧ハンターUIのテストは機能休止により今回の公開ゲート外。
