# チュートリアル v46

## 目的

キャラを中心に見て、迫るノーツを確認する視線に合わせる。
本編へそのまま持ち込める操作感を練習する。v45の「1マス前」「回転しない専用ノーツ」「段階ごとの入力ロック」は廃止した。

## 本編と共有する仕組み

- `input` / `doAction` / `onBeat` / `checkHit` を共有。ノーツがプレイヤーのマスに来る拍でブレイクする。
- `noteView` と通常の描画を共有。回転・進行経路・保存済みのノーツ速度も本編と同じ。
- 通常の判定幅を使用。100 BPMではPERFECT ±45ms、GREAT ±90ms、受付 ±170ms。
- 早い有効入力は押下時刻で採点して到着する拍に実行。イベント処理の遅れによる直前の被弾取り消しも共通。
- 最初の1個を壊したら移動が解放される。以後の移動は拍に合わせる必要がなく、説明のための停止や入力ロックを追加しない。
- 青は1打目で赤になり、その場で次の拍に2打目。紫は到着する拍に「進む」で突進する。
- 必殺技は本編の蓄積量・発動・演出を使用。手動設定ではブレイクを350ms長押し、自動設定では満タンで発動。

練習用の違いは、出題する種類と間隔、案内、ライフを減らさないこと、必殺技の事前蓄積。
新しい判定エンジンは持たない。他の曲の判定位置・判定幅・移動ルールは変更していない。

## キャラ付近の案内

- 説明を画面上部・下部のパネルから、キャラを追う短い吹き出しへ移動。
- 上下の候補から、キャラと近づくノーツに重なりにくい側を選ぶ。画面外へはみ出さないよう調整する。
- プレイヤーのマスに黄色い四隅と上下の小さな目印を描く。ノーツ中央に専用の記号は追加しない。
- ノーツが近いときは補足文を省く。青が赤になったら「赤！ 次の拍でもう1回」を優先する。
- 判定結果は吹き出しと反対側へ配置する。必殺技の演出中は吹き出しを隠す。
- 練習中は背景の拍フラッシュ・画面揺れを止める。

## 連続する練習

1. ブレイク：PERFECTまたはGREATで3個斬る。
2. 移動：空いたマスへ4回進む。連続入力できる。
3. 青：2拍で2回斬る操作を2個で練習する。
4. 紫：「進む」での突進を2個で練習する。
5. 必殺技：エンドレスで使う操作として紹介。練習用に108/120まで事前蓄積し、通常の加算で満タンにして実際に発動する。保存済みの手動・自動設定を尊重する。
6. 仕上げ：通常ノーツと青を混ぜて4個斬る。ガイド音の強制を解除し、ユーザー設定に戻す。

段階の切り替えではプレイヤーの位置も操作もリセットしない。次の出題まで3拍の余白を置くが、その間も自由に動ける。
成功数は失敗しても保持し、ライフは減らない。青の2打目を逃しても本編と同様に期限切れとなり、次のノーツでやり直せる。
コース終端では次のコースへ進み、音源末尾では練習段階を保持して曲をループする。完了後は専用画面から再練習・曲選択へ進める。

## 音

音源は `audio/tutorial.mp3` のまま。v45で解析した約100 BPM、`offset: 0.005` を維持する。
曲の音量は最初から0.7、最初の5段階は拍のガイド音を有効にする。最後はガイド音のユーザー設定に戻す。
曲・ガイド音・描画・入力判定は共通の時計と `beatTime()` を使用する。手動タイミング補正・音量・ガイド音の保存値は書き換えない。

## 検証

Chromiumで、通常ノーツの回転と位置補間、1マス前で斬れず自分のマスで斬れること、連続移動、青の2拍目と失敗後の再出題、紫の突進、実際のタッチ長押しと自動必殺技、完了・再開・音源ループを確認。
320 / 390 / 412px幅で、複数のプレイヤー位置に追従し、説明がキャラを隠さず画面内に収まることを確認。
本編へ戻ったときに練習UI・必殺技の練習用解放が解除され、判定とライフ減少が従来どおりであることも確認。

初見の人がタイミングを理解できるか、説明を目で追わず操作できるかは、実機での試遊で評価する。
