# チュートリアル v47

## 改善の目的

v46はキャラ付近に説明を移しただけで、音ゲーの操作中に文章を読む負担が残った。
v47は「短いお手本を見て、同じ操作を試す」流れに変更する。実践中の説明パネルを撤去する。

## 画面と進行

- 導入：ノーツのない時間に、キャラ付近へ1行だけ表示。最低約2拍の余白を取り、小節境界でお手本へ。
- お手本：本編と同じキャラ・ノーツ・回転・判定位置を使って実演。実際の操作ボタンに指を重ねる。お手本中の成功は判定統計・コンボ・練習進捗に加算しない。
- 受け渡し：「やってみよう」を短く表示し、小節境界から実践へ。
- 実践：説明の文章は表示しない。MISSでも操作を止めず、同じ種類を再出題する。成功数は保持し、ライフは減らない。
- 任意のお手本再生・スキップを上部に用意。繰り返す場合も、それまでの成功数を保持する。
- 新しい操作のお手本中は操作を受け付けない。実践に入ったら、説明のために1歩ずつ止めたり入力をロックしたりしない。
- 青の2打目は文字で説明せず、青→赤の変化、2つの点、実演の打音で示す。
- 必殺技が満タンの待機中だけ「長押し」または「自動発動」を表示。この時間には新しいノーツを出さない。
- 長押しは、お手本の指とボタン下の進行表示で示す。実際の長押しにも同じ進行表示を出す。
- プレイヤーのマスを四隅で示し、練習では接近に合わせて満ちるリングを補助にする。仕上げではリングを外す。
- 判定表示は短く小さくし、COMBO行と画面下の診断テキストは練習中は非表示。診断ログ自体は保存できる。

## 練習の内容

1. ブレイク：1個を斬るお手本。実践はPERFECTまたはGREATで3個。
2. 移動：ノーツのない道で3歩をまとめて実演。拍と無関係な間隔で進み、実践では自由に4歩。1歩ごとの説明や停止はしない。
3. 青：青→赤→破壊を2拍で実演。実践は2個。2打目を逃したら本編同様に期限切れとなり、次のノーツで再挑戦。
4. 紫：「進む」での突進を実演。実践は2個。
5. 必殺技：エンドレスの操作として導入。練習用に108/120から開始し、斬って満タンにするところから実演。手動設定なら350ms長押し、自動設定なら満タンで発動。実践でも108/120からためて発動する。保存済みの設定は変更しない。
6. 仕上げ：曲を戻し、通常・青・紫を混ぜる。6個以上を斬って、残っているノーツがなくなったら小節境界で完了。

お手本と実践の間にプレイヤー位置を戻さない。コース終端では周回する。音源末尾でも段階と成功数を保持し、途中のお手本は同じ段階の導入から再開する。

## 音

前半5段階はSUNO音源をミュートし、100 BPMの単純な伴奏をWeb Audioで予約再生する。
キック・拍のクリック・小さな裏拍・小節頭の低音だけを使う。到着した瞬間の合図だけを待つのではなく、先行する拍から次の入力時刻を予測できる構成にする。

仕上げでは既存曲を音量0.7へフェードインし、専用伴奏を外す。ガイド音はユーザー設定に戻す。
音源や保存済みの音量・手動タイミング補正・ノーツ速度は変更しない。v45で設定した約100 BPM、`offset: 0.005` を維持する。
伴奏も曲も、既存のオーディオ時計と `beatTime()` を使う。ポーズで予約音を止め、再開・ループ時は予約を作り直す。

## 本編との共有

`input` / `doAction` / `onBeat` / `checkHit` / `noteView` を共有する。
プレイヤー自身のマスに来る拍が判定基準であり、1マス前を基準にした専用判定は作らない。
回転・移動経路・青の2拍・紫の突進・必殺技の発動処理も共有。
100 BPMでの判定幅はPERFECT ±45ms、GREAT ±90ms、受付 ±170msのまま。

## 検証と未検証

Chromiumで、お手本から全段階を通した完了、実践中の説明非表示、失敗後の再出題、お手本の再生・スキップ、実際のタッチ長押し、自動発動、ポーズ再開、曲ループ、本編へ戻った際の音とライフ減少を確認。
320 / 390 / 412px幅で、導入の1行が画面内に収まり、キャラに重ならないことを確認。
実時間の音の予約とお手本進行も確認する。

これらは機能・表示の確認であり、初見の人が理解できることの証明ではない。
