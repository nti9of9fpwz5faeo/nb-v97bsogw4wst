# v63 — 初級ダイヤハンターの調整テスト

ホームの「初級ハンターを調整してテスト」から、移動スピード・逃げる総距離・失った有効マスの上限・開始時の距離差を変更できます。数字の直接入力と＋／−に対応し、この端末に保存します。一時停止画面でも変更でき、「この設定で最初から」で反映されます。

仮の初期値は80%・30マス・10マス・5マス先です。確定した難易度ではありません。調整値は初級の調整テストにだけ適用し、通常のランダム出現と既存等級の設定を保持します。ドロンは従来どおり神級のみです。

## 判定

- 速度80%は、有効マス10回分に対して相手が8マス進む設定です。
- 前進して使った有効マスと、待機して失った有効マスを区別します。進めない区間では相手も進まず、失ったマスも増えません。
- 失った有効マスが上限に達するか、相手が設定した総距離を逃げ切ると捕獲失敗です。総距離到達時には従来同様の短い最終入力猶予があります。
- 追いついた時点で捕獲できます。必殺技での通過も有効で、総距離まで追跡を強制する無敵区間はありません。
- ワープ後も距離・取りこぼしを引き継ぎます。設定は開始時にコピーし、途中で変更しても進行中の相手は変わりません。
- 同じ曲・同じ遊び方で比較できるよう、調整テスト中はコース順とランダム譜面のシードを固定します。
- 直前のテスト結果に捕獲／逃走理由、双方の進行距離、失った有効マス、最後の距離差、その回の設定を表示します。
