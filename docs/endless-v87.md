# v87 エンドレス更新

## ルール

- エンドレスだけを50マス＋発生源4マスに延長。5種類の形を維持。
- 破線は4・10・16・22・28・34・40・46・50マス。最後の終点マークは描かない。
- 50マス到達時に即コース継続、速度＋0.1、最大2.2。コンボで加算される記録歩数を条件にしない。
- 終端でのワープ表示・音・曲の再スタートを廃止。Gとノーツを新コースに配置し直した後で加速。
- 曲の最後はAudioBufferSourceNode.loopで繰り返す。終了条件はライフ切れ。
- 曲が一周したら、キャラの実位置・表示位置の両方より後ろにある床だけを0.5秒で消す。道の論理座標・前方・判定は維持。動きを減らす設定では即時に非表示。

## 時計

ゲーム秒は出力時計−songStart−手動補正の連続値。速度の変更でsongStartは動かさない。
endless-clock.jsが速度変更時のゲーム秒・音源秒・倍率を保持し、区分ごとに積分／逆変換する。
音声の倍率はAudioContextの現在時刻で変更するため、出力遅延分だけ先行する音声時計を変更点に使う。
拍・固定ノーツ・アクセントは音源の実際の長さで繰り返す。加速時はガイド音の予約を取消し、新しい拍時刻で予約し直す。
一時停止後も同じゲーム秒と音源位置から再開。演出の時刻の原点は変えない。
コースに付属する古いノーツ・床の演出はコース継続時に解除する。

## 背景で判断したこと

1. 既存のグラデーション・輪・斜め帯・粒をCSSで描画。画風を保ち、画像通信や先読み待ち・解像度依存をなくすため。
2. 速度1.0〜1.5に6種類。1.6以降は6種類目を維持。ENDLESS_SCENES配列に追加できる。
3. エンドレスの破線通過時の色変更を廃止し、加速時に統一。段階の変化を読み取りやすくするため。
4. 購入済みテーマは配色と固有演出を優先し、速度段階で輪と帯の構図を変える。購入した見た目を維持するため。
5. キャラ位置50への到達は通常移動・紫ノーツ・必殺技のいずれでも判定。必殺技で最後の中間線をまたいでも同時に継続する。

WebP画像の追加は不要。背景CSSが読み込めない場合も既存のグラデーションが表示される。

## 記録

- リザルトは「コース ○回突破　速度 ×○」に変更。
- 診断ログ・自動判定履歴・任意プレイ記録にspeed_up / course_continue / song_loopを記録。
- 速度変更点のゲーム秒・音源位置・前後の倍率を保存。
- 加速では曲の周回番号を増やさず、音源ループで増やす。
- 入力履歴の30秒区間は処理フレームでなく、入力発生時の曲の周回に対応させる。
- 既存プレイ記録のwarpsキーは過去データ互換用に残し、coursesキーを追加。画面はコース突破と表示。

## 検証

実行例：

```sh
NODE_PATH="$CODEX_PRIMARY_RUNTIME_NODE_MODULES" CHROMIUM_PATH=/tmp/chromium node --test --test-concurrency=1 tests/*.cjs
```

- 元の35マス・エンドレス50マスについて、5形すべての隣接・重複・画面内カメラ範囲を検査。
- 12段階の速度変更、拍と音源位置の往復変換、固定／不規則な譜面、曲境界を検査。
- ブラウザで同じ音声SourceとsongStartを保つこと、音源一周後のノーツ保持を検査。
- 加速前後・曲境界前後の実際の入力処理で±20msがPERFECTになることを検査。
- 古いガイド音予約の停止と、新しい時計の予約時刻を検査。
- OfflineAudioContextで実音声サンプルの速度変更・ループと時計の一致を検査。
- 一時停止／再開、速度上限、必殺技終端、購入テーマ、再試行、他モード、端末保存を検査。
- 360×640、390×844、412×915、768×1024で描画を確認。
