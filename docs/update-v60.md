# v60 ダイヤハンター試作

追いつけない時間制逃走を廃止し、前進で育てて任意に捕獲する方式へ。

- プレイ開始時のみ28%で抽選。当選した忍者は必ず初級。初回は14マス到達で姿を見せる。
- 接近すると「捕まえる」「育てる」。自動捕獲なし。紫ノーツ・必殺技でも意図せず回収しない。
- 選択は時間切れなし。その場で待っても逃走・成長なし。選択開始から6マス進むと自動見送り。
- 見送りは8マス先へ煙のドロン。全等級で同じ距離。終端付近では次のコースへ持ち越す。
- ワープしても同じ忍者と成長を維持。捕獲後の追加出現はなし。
- 実際の移動マスを累積。35マスで中級、105マスで上級。初回コースの移動も含む。
- 175マス以降35マスごとに0.5%の神級昇格抽選。フレーム数や待機時間では抽選しない。
- 報酬は初級5／中級15／上級40／神級150。捕獲時だけ既存財布・捕獲ミッションに一度反映。
- ゲームオーバー、曲終了、中断では未捕獲分は受け取れない。次回は新しい抽選。
- コース外に成長ゲージと選択ボタン。通常の進む・ブレイク操作は維持。
- セーブ形式、既存ダイヤ、ショップ、曲、キャラクター、広告設定に変更なし。

## 検証

実コードのユニット・連携テスト31件合格。任意捕獲の単発入金、見送り、時間経過で成長しないこと、紫・必殺技相当の移動、ワープ持ち越し、神級抽選の重複防止、終了時失効を確認。既存ミッション／購入／広告報酬／MISS／再開カウントの回帰テストも合格。

数値は初回試作値。実プレイで操作の忙しさ、昇格までの距離、回収の判断を評価する。
