# v69 — ブロックに埋め込むダイヤの2パターン

曲一覧の「ブロックのダイヤ」で切り替える。

- **① ほのかに光る**：ダイヤ入りのブロックに、等級に応じた4段階の白い反射と小さな輝きを付ける。ダイヤの形・色・名称・数値は破壊前に表示しない。周囲への光の輪や点滅は追加しない。
- **② 壊すまで秘密**：ダイヤの有無・等級にかかわらず、通常のブロックと同じ描画。破壊時にダイヤが現れる。
- どちらも同じ出現率と報酬。選択は専用のlocalStorageキーに保存し、プレイ開始時に固定する。

マス上のダイヤと通過による獲得は廃止。通常ブロックはブレイク時、青ブロックは2回目で破壊した時、紫ブロックは突進で破壊した時、必殺技は実際に砕けた時に獲得する。受付時間外の失敗・被弾・被弾直後の自動除去では獲得しない。チュートリアル・ポーズ・終了後も獲得しない。

ダイヤはブロックの生成時に一度だけ決める。ノーツ配置の乱数を消費せず、移動・青から赤への変化・押し返し・必殺技の対象化・遅延入力の復元でも同じダイヤを保持。獲得済みフラグと実行中のブロックIDで二重獲得を防ぐ。

4種類の既存素材と報酬（初級5／中級15／上級40／神級150）を使用。試作の共通設定はブロックごとの出現率8%、ダイヤがある場合の種類比率60%／28%／11%／1%。設定はgems.jsに集約。

破壊直後だけ、ダイヤと獲得数を0.55秒表示。連続破壊の音はまとめ、ワープ時には演出と音の制限時刻をリセットする。リザルトの詳細にはブロックからの獲得数と種類別の個数を表示する。財布・解放・記録・ミッションの既存セーブ形式は維持。
