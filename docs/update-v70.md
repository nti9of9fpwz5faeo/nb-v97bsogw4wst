# v70 — 任意で掘るダイヤブロック

承認された4色の石ブロックをCanvasで立体風に描画。白・青・紫・金を既存の初級・中級・上級・神級に対応させる。外部画像の追加なし。

- ダイヤ割当済みノーツを専用ブロックへ変換。初動ロック中は通常ブロックを保証。抽選率8%、種類比率60/28/11/1、報酬5/15/40/150は既存どおり。
- 何もしない／進んで通過してもダメージ・MISS・報酬なし。
- 最初の拍内ブレイクで採掘開始。その一打を含め4/6/8/12回で破壊（調整値はgems.js）。同一拍は一打のみ。拍外・放置は進捗なし、ライフ減少なし。
- 採掘中は移動・通常ノーツ判定・生成を止め、他ブロックは毎拍その場で回転する。音楽・ガイド・拍時計は継続。進む／必殺技／長押しで採掘を飛ばさない。
- 完全破壊時に一度だけ報酬。1拍の回復時間後、現在の曲の拍で移動を再開する。固定譜面の停止中の生成拍はスキップし、遅延ノーツの一斉放出をしない。音源・拍タイミングは変更しない。
- 亀裂、打撃音、破片、キャラより手前の獲得バッジ。バッジは1.2秒、狭い画面でも端からはみ出さない。
- 曲終了・再挑戦・曲一覧への帰還・ワープで採掘状態解除。未破壊は無報酬。採掘前の必殺技通過も無報酬。
- v69の見え方切替UIを説明に置き換え。旧設定キー、所持ダイヤ、解放、記録、ミッションは保持。
