# v65 — 有効マスの数え漏れを修正

v64ではノーツまでの距離から2を引いて移動可能数を推定していたため、実際の `freeMove` では進める最後の空きマスを数えませんでした。有効マスの減少だけから成功前進数を計算した結果、実際の前進より成功数が少なくなる不具合でした。

- 実際に進める空きマスの数（ノーツまでの距離−1、ゴールまでの距離以下）で機会を数えます。ゴール到着後に進めないマスは取りこぼしに数えません。
- 成功した前進を実移動から数え、盤面の機会減少から同じ前進を除いて待機による取りこぼしだけを数えます。ノーツの入れ替わりや紫ノーツのリベースで成功数を失わず、二重にも数えません。
- ノーツのあるマスへの前進は独立項目とし、活用率から除きます。前進合計＝活かした機会＋ノーツのあるマスへの前進を照合して、結果に表示します。
- 計測とハンターの移動時計は共通の集計処理を使います。必殺技中と着地直後は引き続き別集計です。等級ごとの設定値は変更していませんが、正しく数えることで追跡ペースは変わります。
- エンドレスの加速を区別できるよう、全体と20機会区間ごとの速度範囲、各イベントの速度を記録します。
- 新規記録はschemaVersion 2です。v64の保存記録を残し、旧方式の活用率とは直接比較できないことを明記します。

27件のロジックテストに加え、実際のゲーム操作でノーツ直前への前進を再現し、前進合計との一致、待機・紫・必殺技・ゴール・ワープ・記録ファイルの保存を確認しています。
