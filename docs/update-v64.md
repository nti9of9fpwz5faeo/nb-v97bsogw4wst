# v64 — 普通に1曲遊ぶだけのプレイ記録

ホームの「1曲遊んで記録する」から好きな曲を選びます。4項目の数値調整は必要ありません。前回の手動ハンターテストと必殺技満タン開始を解除し、通常の1曲チャレンジで計測します。ゲームの速度や判定は変えず、プレイ中の表示も増やしません。

## 記録する内容

- 進む機会の数、活かした機会、逃した機会、活用率
- 通常の前進、紫ノーツでの前進、必殺技の移動と回数（実移動を使用し、スコア倍率を含めない）
- 連続で取りこぼした最多マス数、20機会ごとの内訳、タイムライン
- 曲・BPM・譜面バージョン・遊び方・難易度・キャラクター・判定結果・最大コンボ
- 完走／ゲームオーバー／手動中断の区別

ハンターの有無や捕獲後に関係なく計測を続けます。進めない区間は取りこぼしに数えません。必殺技中と着地直後の譜面変化は機会の集計から除外し、ワープ時に位置と時刻を引き継ぎ直します。チュートリアルは対象外です。

結果画面の「プレイ記録を見る・渡す」で確認できます。直近5回を端末に保存し、ホームの「前回の記録を見る」で再表示・選択できます。明示的な共有操作をするまで記録を外部送信しません。

ファイル共有、JSON保存、同じ表示内容のTXT保存、コピーに対応します。コピーAPIが使えない環境では選択可能なテキスト欄を表示します。保存に失敗した場合は画面に表示します。

この記録は曲ごとの実測資料です。プレイヤー全体での順位や初級適性を評価せず、難易度を自動変更しません。初級の設計には初心者側の記録も必要です。
