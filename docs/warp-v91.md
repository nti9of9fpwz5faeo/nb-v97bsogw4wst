# v91：35マスのワープと床の渦

- エンドレスを元の5種類の35マスコースに戻した。始点＋35歩＋出現口用4マスの計40セル。
- 終点の紋章とWARPラベルを、マス内に収まる2本の水色の渦に変更。太い紺色の縁、幅0.8マス・高さ0.56マス。内側だけゆっくり回転し、一時停止中と動きを減らす設定では静止する。
- ワープ時は曲を頭から再開。音声開始前0.12秒と最初の4拍の準備時間を維持。
- ワープごとの速度＋0.1、上限2.2倍、ライフ・スコア・コンボ・必殺ゲージの引き継ぎは維持。必殺技の着地が終わってからワープする。
- 説明文と診断ログも35マスに対応。通常・距離モード、曲の場面による背景演出は維持。

検証：関連単体テスト26件、エンドレスのブラウザテストを通過。35歩目の通常移動、必殺技の着地、15回のワープと速度上限、曲の再開位置、準備4拍、停止復帰、リトライ、他モード、曲終了、スマホ3サイズを確認。約40pxのマス上で渦の表示を確認。
