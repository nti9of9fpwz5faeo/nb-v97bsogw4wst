# v88 エンドレスの連続コース

v87では音声が続く一方で、50マス到達時にプレイヤーとカメラを初期位置へ戻していた。
v88では通過済みの道を世界座標ごと保ち、境目のマスを始点として次の50マスを継ぎ足す。

- 50、100、150…マスで速度変更。倍率・曲・拍・判定の連続時計はv87のまま。
- 新しい道は既存5種類の折り返し列を使用。始点の列に合わせて左右反転し、最初は下2マスへ進んでから横へ折り返す。通過済みの道と重ならず、常に8列に収まる。
- 通過済みの座標、通常移動の補間、進行中の必殺技の移動アニメーションを維持。境目で位置を飛ばさない。
- カメラの現在位置を保存して次の表示範囲へ滑らかに追従。動きを減らす設定でも、境目の瞬間は位置を維持。
- 50マス目に進行方向を横切る黄色の二重線と「加速 ×○」を表示。通過後は水色の線と「速度 ×○」を0.85秒表示。速度上限では加速と偽らず現速度を表示。
- 曲が一周した時の床消去は累積マス番号で管理。コースを継ぎ足しても消去済みの床が戻らない。
- 画面外の床は描画対象から除外。座標はアニメーションと記録の参照用に保持。
- プレイ記録は現在地を保持したまま区間を切り替え、二重に歩数・必殺技回数を加算しない。
- エンドレス以外は従来のコース切替を維持。

検証：全5形×8列の始点、100コースの接続・隣接・重複なし、25回の境界前後の画面座標一致、通常歩行・必殺技、加速ライン、累積位置での床消去、表示負荷、一時停止、既存の曲・判定テストと他モード。

実機での確認：通常歩行／必殺技で境目を越えた時の滑らかさ、黄色ラインの分かりやすさ、曲一周時の後方床消去。
