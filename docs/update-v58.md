# v58 — メニュー・音・復帰の改善

- 曲タブ：全曲を固定順で表示。未解放は鎖とランク／ダイヤ条件。曲のカード内にミッションゲージ。曲選択後に1曲チャレンジ／エンドレスを選択。試聴はアイコンのみ。
- ホーム：キャラ入口を維持。ランクとXPを大きいカードで表示。下ナビのキャラを曲に置換。特別ステージは独立ページ。
- 難易度選択を削除、旧HARD設定を読み込まずNORMAL相当の固定値。旧難易度ごとの記録は削除しない。
- ショップ：ダイヤ購入／広告削除の枠。実決済の設定がないため販売準備中。価格を仮表示したり、購入済みを偽装したりしない。テーマはボタンから別画面。テスト用10万ダイヤの一度限りの受取を折り畳み内に維持。
- ミッション：明るい背景・カード。デイリーは日本時間0時更新、GREAT以上150回・合計150STEPS・必殺技3回（各5ダイヤ）。初期調整値。
- 曲ミッション：曲別にGREAT以上150/500/1500回、最高100/250/500STEPS。各5/8/12ダイヤ。ゲージは各目標の達成割合の平均。旧保存には曲別内訳がないため追加時点からカウント。旧財布・ランク・所有内容を保持。
- MISS：受付時間外の対象あり入力もライフ減少。対象を消費して同じノーツの期限切れとの二重減算を防止。対象なし空振り、練習は従来の保護を維持。
- 復帰：ポーズパネルを即座に閉じ、コース上で5→0の拍カウント。準備中は位置・判定を停止、ノーツのみ回転。中断・タブ切替でカウントを中止可能。
- ヴェノ：既存Firefly素材の強い部分（約0.3秒）を含む切り出しに修正、gain 0.40→0.95。PERFECT/GREAT/GOODで再生速度・フィルタ・短い音程成分を変更。元WAVは無変更。ボタン・解放・MISSにSE追加。UI音もSE音量に従う。
- リザルト：記録・自己ベスト・獲得ダイヤ・再挑戦を中心に。精度・コンボ・ランク進捗などを「くわしい結果」に折り畳み。段階表示と既存Firefly SEを維持。
- 広告2倍：リザルトに入口。NBAdsアダプター未接続時は準備中。視聴完了と同じrunIdの受領結果だけで、今回の獲得ダイヤと同額を追加。永続化・重複防止・保存失敗ロールバック。SDK・広告ユニット・AndroidラッパーはこのWebプロジェクトに存在せず、実広告配信は未実装。Google公式のearned rewardコールバックを利用するホスト連携が別途必要。

## 検証
23件のNodeテスト：既存進行データ、財布、購入、忍者、コース、必殺技、デイリー境界、曲別進捗、広告未完了・重複・保存失敗、入力MISS、復帰カウント。
音声波形の計測で切り出し位置を検証。人間として音を聴いた品質保証はしていない。実機スピーカーで音量バランスを要確認。

## 広告連携仕様（未接続）
`NBAds.configure(provider)`。provider.isReady()は同期boolean。provider.showRewarded({runId})はPromise<{earned:boolean,runId:string}>。
SDKの報酬獲得通知でのみearned=true。単に閉じた場合はfalse。プロダクションではサーバー検証・Google Play Billing対応が別途必要。このlocalStorage台帳で実決済を検証しない。
参考: https://developers.google.com/admob/android/rewarded
