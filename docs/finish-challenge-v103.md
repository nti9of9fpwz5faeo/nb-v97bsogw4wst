# v103 完走チャレンジ

既存エンドレスと別の `finish` モード。曲一覧の「完走チャレンジ」から、登録済みの Futuristic Action を選ぶ。

## 曲と譜面

- 音源は既存 `audio/Futuristic Action.mp3` のまま。実ファイルは64.056秒。
- SONGSの150 BPM、先頭拍0.30秒、既存の演奏区間終端61.3秒を使用。速度1倍、曲のループ・ワープなし。
- 固定のコースと譜面。譜面の赤/青/紫は明示した値で決まり、乱数・ダイヤ採掘は使わない。
- 音源のエネルギー変化を参考に、冒頭、約14.7秒の盛り上がり、33.9秒の間、35.5秒からの厚い区間、54.7秒からの終盤にパターンを分けた。最後の6拍は新規出現を止める。
- 拍の時刻は登録データから生成し、既存の音声時計・判定・青ノーツの足踏み・紫の押し返しを利用する。

## 到達率とライフ

- 到達率はプレイヤーの実際の位置 / ゴール位置。小数1桁を切り捨て、未到達で100%に丸めない。HUDとリザルト、専用ベストに表示。
- 曲の進行に合わせて移動できる範囲が広がる。先行できる余裕を6セル残し、被弾保護中の連続前進を可能にする。ゴールは61.3秒で開き、100%になった時点でクリアする。曲の実終端まで未到達なら失敗。
- ライフ1。被弾直後に終了すると試したい連続前進ができないため、既存の被弾保護0.6秒が終了してから失敗を確定。その間に100%に達すればクリア。ポーズ中は保護時間も停止。
- 通常の「進む」は従来通り即時移動。既存の判定幅によるPERFECT/GREAT/GOOD/MISSを表示するが、移動表示だけではライフやブレイク判定統計を変えない。紫への進む・ブレイクは既存の判定処理。
- 歩数表示・歩数目標・歩数評価はこのモードでは使わない。必殺技の歩数加点も持ち込まない。

## 記録と既存機能

- 新記録は `neon-blade-finish-best:futuristic-finish-v1` に分離。過去モードの記録キーへ書き込まない。
- 既存の曲カード、試聴、ミッション達成率を保持。その下に専用ベスト到達率を別表示。従来通り有効なブレイクは曲別ミッションの達成に寄与する。
- 音声・画像の追加や差し替えなし。
