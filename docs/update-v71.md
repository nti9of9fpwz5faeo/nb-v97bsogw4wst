# v71 — 同じ場所で割れていく通常ダイヤブロック

- 出現する採掘ブロックは通常（初級）だけに限定。4打で破壊、5ダイヤ。既存の4種類の定義や所持・解放・ミッションデータは保持。
- 他ノーツと同じ正面向きの四角形、角丸・輪郭幅・サイズに変更。斜めの立方体は廃止。
- キャラの一つ先のマスに到着する拍からブレイクできる。最初の打撃位置に留まり、キャラのマスにも頭上にも移動しない。頭上用の専用ブロック描画を廃止。
- 1打目：太いヒビと角の欠け。2打目：分岐する割れ目と追加の欠け。3打目：4つの石片が離れかける。4打目：石片が外へ砕け、同じ位置にダイヤが現れる。
- 小さな破片と打撃の瞬間の光を追加。透明な欠けは専用描画面に作り、床を消さない。
- 音楽は継続。採掘中の通常ブロック停止・その場回転、同じ拍の重複防止、スルー無傷、終了時の未破壊無報酬は維持。

検証：mining-browser.test.cjsで先行・遅れ入力、実際の描画座標固定、4段階破壊、通常1種類のみの生成、無被弾、報酬一度きり、再開、ポーズ・リトライ、320px表示を確認。既存の判定・報酬・保存テストも実行。NB_PUBLIC_URLを指定すると公開版を検証可能。
